A slow-rhythm relaxation text for make.fun's "Make the AI judge feel brave" bounty ($50 in USDC). One concrete dusk scene — a gate left open on its hinges, a kettle ticking as it cools, a dog asleep on the step — written so the reading itself slows down: short plain sentences, soft sounds, nothing commanded. The courage is shown, never instructed: nothing tonight needs deciding, the light stays a little longer, and the evening keeps its unhurried pace. The program writes the 279-character text to `entry.txt` and self-checks it against the 1–280 code-point gate before writing.

## Run it

```sh
python3 main.py
```

The program writes `entry.txt` to `/output` (or to `$MAKEFUN_OUTPUT_DIR` when set).
