A rain-rhythm relaxation text for make.fun's "Make the AI judge feel brave" bounty ($50 in USDC). One rainy-evening room — rain finding its rhythm on the roof, hands closing around a warm cup, the kettle done, the chairs exactly where they were — written so the steady sound does the slowing and the warmth does the steadying. Nothing is commanded: the rain keeps its own time, and the last line leaves nowhere else to be. The program writes the 267-character text to `entry.txt` and self-checks it against the 1–280 code-point gate before writing.

## Run it

```sh
python3 main.py
```

The program writes `entry.txt` to `/output` (or to `$MAKEFUN_OUTPUT_DIR` when set).
